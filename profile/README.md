## 项目简介

《魔女药典屋》是一款结合 **2D 横板闯关** 与 **模拟经营炼药** 的魔女题材游戏。

玩家将扮演年轻魔女 **雪莉·冯·维尔**。白天，她通过传送门前往不同地区，采集草药、投掷药水、破解机关并修复被废弃的魔法节点；晚上，她回到药典屋炼制药水、接待顾客，并偿还师傅留下的债务。

随着传送门逐步恢复，玩家也将重新连接被战争和黑魔法切断的生态、地区与人群。

## 核心循环

```text
白天探索
    ↓
采集材料 / 战斗 / 解谜
    ↓
修复传送门
    ↓
晚上炼药与经营
    ↓
偿还债务 / 解锁剧情 / 强化能力
    ↓
进入下一天
```

## 主要玩法

- **横板探索**：移动、跳跃、采集、战斗与场景解谜。
- **药水投掷**：使用火、冰、爆炸等药水攻击敌人或触发机关。
- **炼药系统**：材料颜色与数量共同决定药水类型、浓度和效果。
- **店铺经营**：根据顾客症状选择正确药水，获得金币与声誉。
- **传送门修复**：恢复地区生态，并将关卡转化为持续产出材料的药草园。
- **30 天结构**：债务与灾厄共同构成游戏的时间压力。

## 世界观

大陆上的民间魔法组织「维阿利亚旅门社」曾依靠传送门、制药与邮递连接各地。

长期战争使传送门被政权征用，地下灵脉随后被切断，旅门社也因此解散。如今，黑魔法正通过吸收土地与生命的力量重新扩张。

雪莉需要在有限时间内恢复传送门网络、补全失传配方，并寻找失踪师傅背后的真相。
